重生

發表於 2026-10-27 分類於 誌

事件發生於 2026/10/24 晚餐前，在排除錯誤的過程中，手誤；不，準確地說，不是手誤，是手賤加腦殘。

系統其實跳出了警告訊息，清楚地告訴我按下去之後將刪除且無法復原。只是它用英文寫的，而我不知是哪來的自信，或者說愚蠢，竟毫無懼色地一路按了下去。

按下之後，螢幕沒有閃爍，電腦沒有當機，網路沒有中斷。窗外的車照樣經過，時鐘照樣走動，世界依然平靜如常。只有我還不知道，自己剛剛親手替經營多年的網站簽下死亡證明。

起初並未察覺異狀。直到畫面出現詭異的 404，重新整理，螢幕回傳的 404，再次重新整理，仍是 404；我不信邪，再整理一次，還是 404；我不信邪，改換按下 F5 鍵，依舊是令人背脊發涼的 404。彷彿只要我按得夠快、夠多次，網站就會突然良心發現，自己長回來。答案擺明的，沒有。

我開始覺得事情有些不對勁。

連忙打開 GitHub 上的 blog 專案夾，赫然發現，別說文章，連 blog 本身專案都已經不存在。

那一刻，我開始後悔，無比後悔。

我向 Google 求助，向 Gemini 求助，搜尋 GitHub 是否有辦法救回已刪除的專案。答案並不樂觀。該消失的已經消失，該刪除的已被刪除，連我以為存在的備份，也不復存在。

四百餘篇的文章。數十年的心血，原來消失起來，只需要一個按鈕。

後悔迅速演變成恐慌，無比恐慌。

我開始理解，這不是系統故障，不是網路異常，也不是暫時性的錯誤。它真的死了，徹徹底底地死了。

恐慌隨之而來的是絕望，無比絕望。

唯一的希望，只剩下從電腦裡那些殘存的檔案中，尋找散落各處的碎片，重新拼湊出原本的輪廓。

然而這些年來歷經數次電腦汰換、硬碟搬遷與資料轉移，許多檔案早已流離失所。能否拼回全貌，我毫無把握。

我開始害怕，無比害怕。

我一直以為那些文章都在，放在網路上，放在 GitHub 上，隨時都能讀到，也就理所當然地認為它們安全存在。

直到這一天，我才明白，存在不等於備份；看得見，不代表留得住。

我一直把這四百餘篇文章視為自己的資產，而且是比存款更重要的資產。存款花掉了，至少換來一頓飯、一趟旅行、一件物品，多少會留下些什麼；文章則不同，我以為只要放在那裡，就會一直都在。

可惜我錯了。存款花掉了，還有消費者剩餘；文章消失了，卻只有無比的懊悔。

早期以手動方式直接在 GitHub 上新增 md 檔，電腦裡留下的只有最初的手稿。後來每一次修改、每一次勘誤、每一次增刪字句，幾乎都是直接在線上完成。

今天總算體悟到，自己根本沒有真正完整的網站備份。

如今，唯一的一條路，只剩下重建。

這一次，我要用正規的方式，在本端完成內容與測試，再同步到 GitHub 更新。至少未來若再發生同樣的悲劇，我還會握有最後一道防線。

網站與模板已經在 2026/10/25 測試完成。

接下來，是重大的工程：一篇一篇找回來，一篇一篇放回原來的位置。

然而在此之前，還有一個更加龐大的工程：我要先把那些散落在各個角落的文字殘骸找出來，重新拼湊出屬於自己的歷史軌跡。

四百餘篇文章，究竟能找回幾成，我不知道。

或許七成，或許五成；或許有些文章，將永遠消失在歲月與硬碟的縫隙裡。

找回來的，是文章；找不回來的，也是文章。這次網站重生，重生的是網站。不是文章。
