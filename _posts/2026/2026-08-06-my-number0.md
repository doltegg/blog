數線世界裡，沒有哪個數字，比 0 更令人敬畏。

它既不是正數，也不是負數；不是質數，也不是合數。既沒有正面的身份，也沒有反面的歸屬。它只是靜靜地站在原點，看著所有數字來來去去。

<!--more-->

於是，0 找上了玄虛上師。

上師看了看它的命盤，只問了一句：「你是不是常覺得自己什麼都不是？」

0 默默地點了點頭。心裡卻像被戳中最深的傷口——那種空洞感，瞬間湧上來，讓它覺得自己真的是一個透明的影子。

上師長嘆一聲：「你這不是普通命格，你命犯『空亡』。」

0 心頭一震，胸口像被壓住：「上師，可有破解之法？」

上師指著命盤說：「你與任何數字相加，看似什麼都沒改變：a + 0 = a。與任何數字相減，也像從未存在：a - 0 = a。別人努力半天，你一出現，結果還是一樣。久而久之，你自然容易懷疑自己的存在。」

0 默默低下了頭，心裡泛起一股無力感。它突然覺得自己像是永遠的旁觀者，無論誰經過，自己都不會留下痕跡。

上師又翻了一頁命書，沉聲道：「但你的命，真正霸道的還不是這裡。任何數，只要乘上你，一生修為盡毀——a × 0 = 0。無論對方是 7、97，還是 10^100，只要與你交會，最後通通歸於零。更別說若是有人妄想把你放在分母來除你，直接會引發宇宙規則坍塌的『無意義』大劫。」

0 臉色發白，心裡一陣顫抖：「那……我是天煞孤星？」

上師卻搖了搖頭：「不，你不是。你是『眾生平等』。你從不偏心，萬物終將歸零，這正是你的慈悲。」

0 聽得心情稍微平復，眼神裡閃過一絲光亮：「那我還有救嗎？」

上師忽然露出一絲笑意：「有。這世上，沒有你，就沒有『位值』。1 與 1000，只差三個你；10^9 若沒有你，也只剩下一個孤伶伶的 1。你看似什麼都沒有，其實，是你讓別人變得偉大。」

0 愣住了。心裡第一次泛起一種奇異的暖意。它忽然明白，原來自己的存在不是為了成就自己，而是為了成就他人。

它抬起頭，看著無窮延伸的數線，心裡默默地想：「或許，真正的存在，不是被看見，而是讓別人被看見。」

第一次，它覺得自己的命，好像真的沒有那麼糟。
